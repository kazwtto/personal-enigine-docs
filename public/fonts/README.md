# Font assets

These files are stored locally so the documentation does not depend on a third-party font request at runtime.

- `JetBrainsMono-Regular.woff2` and `JetBrainsMono-Bold.woff2`: [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/webfonts)
- `Monocraft.ttf`: [Monocraft](https://github.com/IdreesInc/Monocraft)
- `8bitOperatorPlus-Regular.woff` and `8bitOperatorPlus-Bold.woff`: [DELTARUNE web assets](https://deltarune.com/assets/fonts/)

Review each upstream project's terms before redistributing the site outside this project.
